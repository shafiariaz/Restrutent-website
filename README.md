# Zahra Dining
### Premium Multi-Purpose Restaurant Website Template

**"Where Every Meal Becomes a Memory."**

A modern, luxury restaurant template built for fine dining, bistros,
steakhouses, pizzerias, cafés, and multi-concept restaurant groups.
100% responsive, framework-free, and fully customizable from a single
configuration file.

---

## ✨ Features

- **17 complete sections** — sticky header, hero with rotating imagery
  and a floating quick-reservation bar, about, featured dishes, a
  16-category tabbed menu, chef profile, gallery with lightbox,
  reservation form, testimonials slider, events, catering, special
  offers, FAQ accordion, newsletter, Instagram grid, Google Maps
  embed, contact form, and a full footer.
- **One-file customization** — `js/config.js` controls restaurant
  name, logo, contact details, hours, all colors, every image, the
  entire menu, and social links. No HTML or CSS editing required.
- **58-dish sample menu** across Starters, Soups, Salads, Pizza,
  Burgers, Pasta, Steak, Seafood, BBQ, Chicken, Desserts, Coffee,
  Drinks, Mocktails, Kids Menu, and Chef Specials — real dish names,
  descriptions, and prices, zero Lorem Ipsum.
- **100% vanilla** HTML5, CSS3, and JavaScript — no Bootstrap, no
  jQuery, no build step, no dependencies to install.
- **Fully responsive** — tested down to small mobile widths.
- **Performance-minded** — lazy-loaded images, no render-blocking
  scripts, clean semantic markup.
- **Accessible** — visible focus states, semantic landmarks,
  keyboard-friendly lightbox and accordion, reduced-motion support.
- **Built-in online ordering system** — a full delivery/pickup flow
  (`order.html` → `cart.html` → `checkout.html`) with a slide-out
  cart drawer, quantity steppers, delivery/pickup and payment-method
  selection, order-ID generation, and a pre-filled WhatsApp order
  message. Menu items live in `data/menu.json`. See
  `documentation/online-ordering-guide.md` to configure it.

---

## 🚀 Quick Start

1. Unzip the template.
2. Open `index.html` in any browser to preview it immediately.
3. Open `js/config.js` and follow
   `documentation/customization-guide.md` to make it yours.
4. Upload the whole folder to any static host (Netlify, Vercel,
   GitHub Pages, or your own web host) when you're ready to publish.
